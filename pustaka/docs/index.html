The graph is the primitive, not the prompt.

GAOS runs software agents against a product record that lives in a graph. State is in vertices and edges rather than a conversation, every change emits an event, and the orchestrator holds nothing — kill it mid-run and it rebuilds from the graph.

The product

    
Three things, and the first one is a claim

    
GAOS is an orchestration model, an operator surface, and the infrastructure both run on.
    Only the first of those is finished as a design; the other two are deliberately at pass one,
    and each page says which parts are not built yet.

  


  

    
      
The system →

      
Six layers, five control loops, a scoring function with a safety floor, and a readiness
      rubric the planner refuses to work below. Plus what happens when the orchestrator restarts.

    
    
      
The graph →

      
25 vertex types, 32 edge types and an append-only event stream in ArcadeDB — with the two
      edge directions that are easy to get backwards and expensive to fix later.

    
    
      
The infrastructure →

      
Two machines and one public IP: a 1 vCPU edge that terminates TLS, and a private VM with no
      public address that runs every container.

Design

    
Why a graph

  

  

    
A prompt chain has no addressable state

      
You cannot ask it what a task depended on, which requirement justified a decision, or what
      was sent to the model on attempt two. In a graph each of those is a traversal.

    
Kill the orchestrator, lose nothing

      
It holds no authoritative state. On restart it reconciles running tasks against a workspace
      lease and a heartbeat, then adopts, requeues, or fails them as orphaned.

    
Unwritten is unhappened

      
Every change emits an event from a closed catalog. State at any moment is a fold over the
      stream from the nearest snapshot, which is what makes a run replayable at all.

    
Refuse a vague record

      
Readiness is scored out of 100 by machine-checkable rules, and decays when nobody reads it.
      Below 45 the planner will not plan — a vague spec produces a vague plan.
